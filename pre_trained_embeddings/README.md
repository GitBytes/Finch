# Pre-trained ChemBERTa Embeddings

This folder contains files related to ChemBERTa embeddings for chemical compounds with a focus on liver toxicity data:

- `chemberta_pre-trained-LIVER.ipynb`: Jupyter notebook for generating embeddings using pre-trained ChemBERTa
- `KIM_pubchem_hepg2_chemberta_embeddings.csv`: Chemical compound data with initial embeddings
- `KIM_pubchem_hepg2_chemberta_embeddings_PRETRAINED.csv`: Chemical data with pre-trained ChemBERTa embeddings

The dataset includes chemical compounds with toxicity measurements and 384-dimensional embeddings generated from the ChemBERTa model.
